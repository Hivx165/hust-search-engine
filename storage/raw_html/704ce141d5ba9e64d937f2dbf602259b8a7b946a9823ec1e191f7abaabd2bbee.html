      Mô tả thiết bị

      Camera chiếu vật thể kỹ thuật số Samsung No S 2120397

      Thông số kỹ thuật

      -  Hệ thấu kính: F=1.5 (Wide)~2.1(Tele), f=5.2~66.5mm
      -  Độ phóng đại ảnh: 12X Power Zoom, 3X Digital Zoom
      -  Vùng chụp hình: Max: 299 x 244mm. Min: 21 x 16mm
      -  Bộ cảm biến: 1/3" 850,000 Pixels PS CCD

      -  Tự động điều chỉnh màu sắc của ảnh.
      -  Chế độ chiếu âm/ dương bản
      -  Tỷ lệ hình / giây: 20 frames/s
      -  Chức năng bắt giữ hình
      -  Đầu ra tín vào: VGA x 2
      -  Đầu ra tín ra: VGA x 2, Video x 1, USB x 1, DVI x 1, RS-232 x 1, S-Video x 1
      -  Độ tương thích PC: XGA (1024 x 768) Pixels
      -  Trọng lượng: 4.8kg
